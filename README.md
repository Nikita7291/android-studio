# Практический экзамен ГИБДД

Android-приложение для подготовки к практическому экзамену в ГИБДД.
Проект разрабатывается в **Android Studio** на языке **Kotlin**.

## О приложении

Приложение помогает курсантам автошкол и всем, кто готовится к сдаче
практического экзамена в ГИБДД, отрабатывать и запоминать ключевые
моменты экзамена: порядок выполнения упражнений, типичные ошибки,
правила движения и порядок действий на площадке и в городе.

## Возможности

- Список экзаменационных упражнений (площадка) с пошаговым разбором.
- Описание типичных ошибок и штрафных баллов.
- Тренировка последовательности действий перед началом движения.
- Краткие памятки по ПДД, относящиеся к практическому экзамену.
- Удобный просмотр материалов на телефоне или планшете.

## Стек и требования

- **Язык:** Kotlin
- **IDE:** Android Studio
- **Минимальная версия Android:** Android 7.0 (API 24)
- **Целевая версия Android:** Android 14 (API 34)

## Запуск проекта

1. Установите [Android Studio](https://developer.android.com/studio).
2. Клонируйте репозиторий и откройте папку проекта в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Подключите устройство или запустите эмулятор.
5. Нажмите **Run ▶**, чтобы собрать и запустить приложение.

Сборка из командной строки:

```bash
./gradlew assembleDebug
```
