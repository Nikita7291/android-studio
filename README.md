# Практический экзамен ГИБДД

Android-приложение для подготовки к практическому экзамену в ГИБДД.
Проект разрабатывается в **Android Studio** на языке **Kotlin**.

## О приложении

Приложение помогает курсантам автошкол и всем, кто готовится к сдаче
практического экзамена в ГИБДД, разбирать экзаменационные упражнения
и запоминать порядок действий: что сделать перед началом движения,
как выполнять парковку, заезд в бокс, эстакаду и разворот.

## Планируемые возможности

- Список экзаменационных упражнений (площадка) с пошаговым разбором.
- Описание типичных ошибок.
- Памятка по действиям перед началом движения.
- Удобный просмотр материалов на телефоне или планшете.

## Планируемый стек и требования

- **Язык:** Kotlin
- **IDE:** Android Studio
- **Минимальная версия Android:** Android 7.0 (API 24)
- **Целевая версия Android:** Android 14 (API 34)
